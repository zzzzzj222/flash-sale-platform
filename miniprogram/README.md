# 微信小程序接入示例

这里提供调用业务后端的 TypeScript 请求封装。服务接入密钥保存在业务后端，小程序使用自己的用户会话令牌。

接入时，业务后端需实现微信登录兑换与业务用户绑定，并提供 `/sale/activities`、`/sale/requests`、`/sale/requests/{id}`、`/sale/requests/{id}/cancel`。业务后端调用秒杀服务时注入可信 `userId` 和接入方身份，校验请求归属。

小程序取得 `RESERVED` 后，由业务后端创建订单并提供微信支付参数。支付回调经后端验签后，调用秒杀服务的确认接口。订单创建失败时，业务后端主动释放预占。支付晚到的退款处理由业务系统承担。

示例尚未绑定真实 AppID、业务域名、微信登录或支付商户。需要在微信开发者工具的 TypeScript 小程序项目中引用 `sale-api.ts`，传入已配置的业务后端 HTTPS 域名与用户令牌。轮询使用间隔与退避策略，终态后停止。
